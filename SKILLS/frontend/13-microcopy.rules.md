# Frontend Skill｜Microcopy 與可理解性（UI Copy）

## 目的
確保 UI 用語對目標使用者可理解，不暴露實作細節。

---

## 強制規則（Must）

- 所有操作文字必須描述「動作 + 對象」
- UI 不得顯示使用者看不懂的內容，包括：
  - DB 欄位名
  - API 參數
  - enum code
  - 技術縮寫

- 必要技術名詞需提供說明（tooltip / help text）

---

## 文案原則

- 說明「發生什麼事」
- 說明「接下來可以怎麼做」
- 避免責怪使用者

---

## 禁止行為（Forbidden）

- Submit / OK / Do it 等模糊動詞
- 僅顯示錯誤碼
- 讓使用者猜下一步
