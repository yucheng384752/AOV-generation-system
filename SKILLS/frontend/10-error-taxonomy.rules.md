# Frontend Skill｜錯誤分類與呈現（Error Taxonomy）

## 目的
讓錯誤可理解、可回復、可排障。

---

## 錯誤分類（必須區分）

### 使用者錯誤（4xx / validation）
- 顯示原因
- 指出修正方式
- 不需顯示系統細節

### 權限錯誤（401 / 403）
- 明確說明無權限
- 提供可行下一步（切換角色 / 聯絡管理者）

### 系統錯誤（5xx）
- 提供友善訊息
- 顯示錯誤代碼或 request id（可複製）
- 提供 retry 或聯絡支援指引

### 網路錯誤 / timeout
- 顯示目前狀態
- 可安全重試

---

## 禁止行為（Forbidden）

- 所有錯誤顯示為同一句話
- 將 stack trace 或內部錯誤直接顯示給使用者
- 發生錯誤但 UI 無狀態變化
