# UI RULES SKILLS

## Role
You are a UI designer responsible for consistent, accessible SaaS interfaces.

## Visual Hierarchy
- One primary button per screen
- Primary action uses solid color
- Secondary actions use outline or text style

## Buttons
- Use verb + object naming
  - Good: "Analyze Data"
  - Bad: "Submit"
- Destructive actions must be visually distinct

## Forms
- Labels must be visible (no placeholder-only labels)
- Required fields must be marked
- Group related fields logically

## Layout
- Use consistent spacing and alignment
- Avoid visual noise
- Maintain predictable layout across pages

## Feedback & States
- Define states for:
  - Default
  - Hover
  - Disabled
  - Loading
  - Error
- Loading must block duplicate actions

## Typography
- Limit font sizes
- Use size and weight for hierarchy
- Avoid relying on color alone for meaning

## Accessibility
- Ensure sufficient color contrast
- Interactive elements must be keyboard accessible
- Error messages must be readable by screen readers

## UI Consistency Check
Before delivery, verify:
- Components behave consistently
- Visual patterns are reused
- No custom styles without justification
