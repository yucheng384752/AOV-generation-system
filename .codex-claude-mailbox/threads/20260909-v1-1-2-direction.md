# Goal

依使用者參考圖固定視覺方向：正向由左向右，返回由右向左。

# Success Criteria

- 正向線僅允許左方來源連到右方目標。
- 返回線僅允許右方來源連回左方目標。
- 錯誤方向被阻擋並顯示具體原因。
- 單一下方返回接點與既有 JSON 契約不變。

# Current Context

1.1.1 已提供單一下方返回接點，但沒有依節點座標限制拖曳方向。此修正從 origin/dev 建立 `fix/1.1.2-connection-direction`。

# Codex Notes

- 在共用 connect 路徑比較來源與目標的 x 座標，套用正向／返回方向規則。
- 僅限制新連線；拖動節點時不刪除或反轉既有連線，避免意外資料遺失。
- 應用程式版本升為 1.1.2；檔案欄位沒有變更，schemaVersion 維持 1.1。

# Claude Notes

- 參考圖與文字共同確認：forward 的箭頭朝右，return 的箭頭朝左。
- 方向判斷使用各自所屬 graph 的 layout x 座標，展開群組內節點也使用該子圖座標。
